# Mundo SENAI 2026 — Segmento de TI

Portal de apoio a quatro oficinas práticas de tecnologia, com duração de **2 a 4 horas**, voltadas a participantes sem conhecimento prévio.

## Oficinas

| Oficina | Conteúdo | Materiais |
| --- | --- | --- |
| SOS Computador | Rufus, BIOS/UEFI e diagnóstico de sistemas | [Acessar](https://github.com/sammyfreitas/oficina-sos-pc) |
| Hacker do Bem | Segurança digital, phishing e proteção de dados | [Acessar](https://github.com/sammyfreitas/oficina-seg-digital) |
| Conecte a Empresa | Redes, IP e Cisco Packet Tracer | [Acessar](https://github.com/sammyfreitas/oficina-redes) |
| Meu Primeiro Robô com Python | Automação de processos e cadastro de produtos | [Acessar](https://github.com/sammyfreitas/oficina-automacao) |

## Portal

Endereço previsto após ativação do GitHub Pages: https://sammyfreitas.github.io/mundo-senai-2026/

O portal terá navegação por etapas, orientações práticas, modo claro/escuro e links de download dos materiais de cada oficina.

## Estrutura planejada

- `index.html` — página inicial.
- `assets/` — imagens e identidade visual.
- `css/` e `js/` — estilos e scripts.
- `oficinas/` — páginas de orientação.

## Desenvolvimento

Materiais e páginas em preparação. Os repositórios das oficinas armazenam arquivos de apoio; gabaritos restritos não devem ser publicados.
